O objetivo principal desta tarefa é que você ponha em prática a criação de testes para operações básicas de banco
de dados, utilizando o conhecimento adquirido ao longo do módulo. Apesar de terem sido apresentados vários exemplos
com diferentes tecnologias (PostgreSQL, MySQL, MongoDB, Spring Data, Docker), você NÃO precisa implementar todos eles.

## O que é esperado:

Escolher uma das tecnologias apresentadas (PostgreSQL, MySQL ou MongoDB) OU uma combinação entre elas, conforme você
se sentir mais confortável.

Criar uma aplicação simples conectando-se ao(s) banco(s) escolhido(s).
Implementar operações básicas (CRUD) e escrever testes automatizados para elas, utilizando um framework de testes
como JUnit. Demonstrar, por meio do seu código, que consegue fazer a integração com o(s) banco(s) de dados e testar
as operações propostas.

## Exemplo de roteiro:

- Escolha o banco de dados e configure sua conexão (pode ser PostgreSQL, MySQL ou MongoDB, via Docker ou
instalado localmente).

- Crie uma entidade simples (ex: Usuário, Produto, etc.) e o respectivo DAO ou Repository.

- Implemente e teste operações CRUD utilizando JUnit.

> Se quiser, pode usar o Spring Data, mas não é obrigatório.

**Não é obrigatório usar Docker** ou todas as tecnologias ao mesmo tempo - escolha apenas o que fizer mais sentido para
você neste momento, mas mostre que compreendeu como testar a integração com banco de dados.
